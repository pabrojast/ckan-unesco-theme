renderizando esta plantilla (home/robots.txt). La ruta explicita gana a los

(super()) se conservan. Solo se usan * y $, que es lo que entienden Google y
Bing. Sin lineas en blanco dentro del grupo: hay parsers que cierran el grupo
en la primera. La regla equivalente para la etiqueta meta robots esta en
crawl_policy.listing_noindex.

# Sort order of one facet inside a listing, as the first query parameter
# (/dataset/?_groups_sort=name). Every value is another URL for the same
# results.

# (/documents/?groups=x&_groups_sort=name).

# Catalogue listings with two or more query parameters: combinations of
# filters, or a filter plus a page number or a sort order. One parameter
# stays crawlable (/dataset/?groups=x, /dataset/?page=2), and so does every
# dataset page (/dataset/<name>).

Disallow: /dataset/?*&
Disallow: /documents?*&
Disallow: /documents/?*&
Disallow: /learning?*&
Disallow: /learning/?*&
# The page of one group or organization is also a listing with filters.

Disallow: /organization/*?*&
# The same listings under a language prefix (/es/dataset/, /fr/group/<name>).
