# docs/obsidian-vault

Vault de [Obsidian](https://obsidian.md) con la documentación interna de `ckanext-theme-ejemplo`, la extensión CKAN para el portal de datos hídricos de UNESCO.

## Cómo usar

1. Abrir esta carpeta como vault en Obsidian
2. Empezar por `Index.md` para navegación
3. Usar el grafo de relaciones para explorar conexiones

## Contenido

| Nota | Descripción |
|---|---|
| Index.md | Punto de entrada y mapa de navegación |
| Arquitectura.md | Diseño del plugin, interfaces, caching, modelos |
| Estructura del Repo.md | Mapa de carpetas y archivos con líneas de código |
| Setup Local.md | Guía de instalación del entorno de desarrollo |
| Comandos Utiles.md | Referencia rápida de comandos |
| Variables de Entorno.md | Claves de configuración y variables de CI |
| Flujos Importantes.md | Flujos de negocio clave (indexación, membresías, admin) |

| Testing.md | Estrategia y ejecución de tests |
| Deployment.md | CI/CD y proceso de release |
| Troubleshooting.md | Problemas comunes y soluciones |
| Glosario.md | Terminología del dominio |
| Guia de Mantenimiento.md | Cómo mantener esta vault |
| Backlog Documentacion.md | Vacíos conocidos por documentar |

## Mantenimiento

Ver `Guia de Mantenimiento.md` para reglas y convenciones.

Esta vault es la **fuente de verdad humana** del proyecto. Los archivos `CLAUDE.md` y `AGENTS.md` en la raíz del repo contienen reglas operativas para asistentes de código y referencian esta vault.
